# Скользящий шаг стартов; «Хвостовой интервал» упразднён

Сетка интервалов жёстко равняла шаг длительности и дорисовывала серый «хвостовой» остаток дня. Решено (билет #3 карты wayfinder): «Шаг стартов» — необязательный атрибут Встречи (`startStepMin`), по умолчанию равен её длительности; сервер принимает любой целый шаг `1 ≤ step ≤ durationMin` (каталог длительностей из ADR-0002 остаётся нормативным только для UI-пресетов). Сетка предлагает исключительно старты, у которых полная длительность вписывается в Рабочий день; статус «хвостовой интервал» упраздняется — Интервал либо целый, либо его нет.

## Considered Options

- Хвост как переключатель semantics (только при step==duration) — статус зависел бы от параметра, отказ.
- Серый обрезанный старт при плотном шаге — три правила вместо одного инварианта.
- Whitelist шага из канонического набора — противоречит ADR-0002 (каталог для UI, не для API).
- Жёсткое «step — делитель duration» — спекулятивное ограничение без доменной нужды.

## Consequences

Пересечение отрезков (`busyByOwner`/`overlapsAny`) уже корректно обрабатывает плотные сетки: одна Запись блокирует все пересекающиеся старты. «Свободно N» при этом означает число бронируемых стартов, а старты могут пересекаться между собой. Упразднение хвоста затрагивает контракт (`SlotStatus.tail`), генератор сетки, UI-метку «Мало времени» и тесты — это работа отдельной build-спеки, не этой карты.
