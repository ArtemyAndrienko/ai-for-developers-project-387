# SQLite (modernc.org/sqlite) как embedded-хранилище

Хранилище пилота — Go-структуры в памяти, которые по плану меняются на
embedded. Выбрали SQLite на чистом Go-драйвере modernc.org/sqlite: предметная
область реляционная (занятость по (Организатор, дата) с пересечениями отрезков,
Записи по почте Посетителя), и SQL выражает её напрямую без самодельных индексов.

## Considered Options

- **bbolt** (чистый Go, KV): проще, но индексы «по организатору+дате» и «по
  email посетителя» пришлось бы строить руками поверх map-модели.
- **JSON-снапшот файла**: честный шаг от in-memory, но хрупкий формат и та же
  ручная работа с запросами.
- **CGO-драйвер mattn/go-sqlite3**: тот же SQLite, но cgo ломает простоту
  сборки в WSL и на CI-раннерах.

## Consequences

Только stdlib `database/sql` + один драйвер; никаких нативных зависимостей;
тесты можно гонять на in-memory базе.
